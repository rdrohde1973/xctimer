# ADR-0012: Provisional: For the fun-run focus, should the offer be "your first event free" (a promo code

- **Status:** provisional
- **Date:** 2026-11-05
- **Cites:** Q-0007

## Context

The "time your own event" flow already exists at xctimer.com/host. An organizer builds the event for free and pays $50 through Square to go live, and the app has promo codes where 100% off publishes for free. Most fun-run organizers hold 1–4 events a year, so a monthly subscription is a poor fit; "first event free" is a natural free tier that needs no new billing code. You'd create the promo code yourself in the app admin. School and district monthly pricing can stay a secondary message.

## Decision

Until the owner answers Q-0007, the team proceeds with: First event free via a campaign promo code (name PROVISIONAL), then $50 per event. Schools are mentioned as a secondary line.

## Consequences

Revisit when the owner answers. Never promoted to accepted by an agent.

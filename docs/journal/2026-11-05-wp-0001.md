## Summary

Added scripts/marketing/check_docs.py (stdlib only) with checks (a) required headings, (b) bare $/%/"N customers" stats need PROVISIONAL(Q-NNNN) or [src: ...] on the same line, (c) leftover TODO/TBD/XXX, (d) "## Summary" in first 20 lines. Prints file:line: reason, exit 1 on violations, else 0. Fixtures in scripts/marketing/fixtures/: pass.md, fail_missing_heading.md, fail_price.md ($49/mo), fail_percent.md (40%), fail_todo.md, fail_no_summary.md. Runner scripts/marketing/test_check_docs.py asserts exit code and file:line message for each.
Verify: `python3 scripts/marketing/test_check_docs.py` (exit 0, six PASS lines). Manual: `python3 scripts/marketing/check_docs.py scripts/marketing/fixtures/pass.md --require Summary --require Offer --require Audience` exits 0.

## Where the agent was wrong

Miscounted the planted-violation line numbers in the test expectations (said line 8, actual 7), and my first pass fixture had a bare TODO beside a PROVISIONAL marker. Both were caught by running the tests and fixed.

## Judgment calls

Heading match is case-insensitive and whitespace-normalised. Missing-heading and missing-Summary errors are reported at line 1. TODO/TBD/XXX are allowed only where the text is inside a PROVISIONAL(Q-NNNN) marker, which is stripped before matching. Fenced code blocks are not skipped. The "N customers" pattern also covers users, clients, contractors, teams, companies and businesses, with an optional one-word qualifier such as "active".
